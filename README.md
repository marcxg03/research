# Research

My research software and analysis pipelines, built as an RA and lab manager at the Oishi Lab (University of Chicago) and for related collaborations. Each project lives in its own repo. This page lists what each one does and where it stands.

## Projects

| Project | What it is | Status | Access |
|---|---|---|---|
| [epiphany_scraper](https://github.com/marcxg03/epiphany_scraper) | Retrieves narrative examples for research on epiphanic narrative sequences (my primary project; poster presented Apr 2026) | Active | Public |
| [bot-detector](https://github.com/marcxg03/bot-detector) | Streamlit app that flags bot responses in survey CSV data (Freedom of Expression study) | Delivered | Public |
| [web_scraper](https://github.com/marcxg03/web_scraper) | Streamlit tool that collects narrative text passages from Reddit and the web, with passage extraction by Claude | Delivered | Public |
| [study-abroad-control-scraper](https://github.com/marcxg03/study-abroad-control-scraper) | Streamlit tool that finds and scrapes Reddit control-group users for study-abroad psychology research | Delivered | Public |
| [responsibilism-analysis](https://github.com/marcxg03/responsibilism-analysis) | County-level computational cultural psychology: Reddit corpora + word2vec cultural dimensions (Kozlowski, Taddy & Evans 2019 method) | Active | Private (unpublished collaborative work, available on request) |
| [study2-preprocessing](https://github.com/marcxg03/study2-preprocessing) | Cleans, merges, and translates open-ended responses across 4 datasets for the Dimensions of Wellbeing Study 2 NLP analysis | Handed off (Apr 2026) | Private |
| [housing-classifier](https://github.com/marcxg03/housing-classifier) | Housing Affordability Study 2 (Russell Sage Foundation): a Claude-based classifier that labels Reddit users' subsidized-rental housing status with a 17-rule codebook. Reproducibility-tested and checked against a 192-case blind validation set; its labels feed a staggered DiD / event-study design | Active | Private (unpublished, available on request) |
| Oishi Lab agent fleet | 11 scheduled agents that run lab operations: the Zoom meeting becomes a transcript, recap and action items in Drive + Slack; each project gets a Doc ledger and Slack canvas; presenter-schedule and roster changes are proposed for human approval; the agents check their own health weekly. Earlier prototypes are in [oishi-lab-workflows](https://github.com/marcxg03/oishi-lab-workflows) | Live (Fall 2026) | Private (lab internal) |

## Themes

- Narrative identity: epiphanic sequences, narrative example banks, passage extraction from natural text.
- Data quality: bot detection and participant screening for online survey research.
- Computational cultural psychology: geographic corpora, embeddings, cultural dimension projection.
- Research operations: AI-assisted lab workflows and automation.
